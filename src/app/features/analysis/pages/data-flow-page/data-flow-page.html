The diagram always renders left-to-right with a teal/green palette.

Entry Points

Entry Points are the files where external requests or user interactions first arrive in the system. The top 5 are shown, chosen by how many other files reference them — which tends to reflect how central they are to the system's surface area.

Files are classified as entry points based on their name containing terms like "controller", "handler", "endpoint", "api", "route", "page", "component", "screen", or "view". No AI is involved — this is purely name-pattern matching.

External Dependencies

External Dependencies are files that appear to represent integration points with the outside world — third-party APIs, external services, or adapter layers. They're identified by name matching: files containing terms like "client", "gateway", "provider", "adapter", "proxy", "connector", "integration", "webhook", or "http" are flagged. Up to 8 are shown.

These are worth knowing about because their behaviour isn't controlled internally — a change in an external service or API can break the codebase in ways that no amount of internal testing will catch.
