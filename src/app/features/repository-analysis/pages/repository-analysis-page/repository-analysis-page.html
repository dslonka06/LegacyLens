Code Health

Complexity is measured by dividing the number of dependency edges in the file graph by the number of nodes (files). A ratio of 2 or below is Low, 2–4 is Medium, and above 4 is High. Higher ratios mean more cross-file coupling, which makes it harder to reason about any individual file in isolation.

Maintainability combines file count with coupling density. More than 100 files and a ratio above 3 = Low. More than 50 files or a ratio above 2 = Medium. Otherwise = High.

Risk Level combines those two scores: High complexity or Low maintainability = Critical; Low complexity and High maintainability = Healthy; either score being Medium = Fair; any other combination = Needs Attention.
